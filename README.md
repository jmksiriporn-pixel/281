# เว็บไซต์บทเรียนออนไลน์: มารยาทในการติดต่อสื่อสาร
สำหรับนักเรียนชั้นประถมศึกษาปีที่ 5

## จุดเด่น
- ธีมสีฟ้า–เหลืองตามภาพตัวอย่างและภาพการ์ตูนที่ให้มา
- บทเรียน 4 บท พร้อมอินโฟกราฟิกประจำบท
- แบบทดสอบก่อนเรียน 10 ข้อ และหลังเรียน 10 ข้อ
- เกม 4 กิจกรรม
- ใบงานวิเคราะห์สถานการณ์
- หน้าสรุปคะแนน
- หน้าผู้จัดทำพร้อมรูปภาพ
- บันทึกคะแนน/ความคืบหน้าด้วย LocalStorage

## GitHub Pages
